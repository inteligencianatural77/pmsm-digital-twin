\section{Discusión}

La discusión deberá separar las propiedades de la planta de las del controlador y de las que pertenezcan a la capa inteligente. El FOC se considera la base de control establecida, mientras que ANFIS, MPC y Tiny/TinyML representan las líneas de investigación y desarrollo que deberán demostrar un beneficio cuantificable.

La presencia de no linealidades no se inferirá únicamente a partir de que $L_d=L_q$ en el modelo base. Deberá demostrarse mediante datos, mapas o discrepancias sistemáticas entre el modelo base y el comportamiento observado.
